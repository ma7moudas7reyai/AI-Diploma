Corrections and research notes
- In the exact string "mahmoud ashrey", the character "a" occurs at indices 1 and 8, not 1 and 9.
- List comprehension is concise, but it is not universally the fastest or best solution. The right method depends on target semantics, overlap rules, memory needs, and whether the target is a literal or a pattern.
- Python string indices refer to Unicode code points, not encoded byte offsets and not necessarily user-perceived grapheme clusters.
