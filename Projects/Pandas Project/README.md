# Brazilian E-Commerce Analysis

An exploratory data analysis project based on the Brazilian Olist e-commerce dataset. The notebook loads and validates multiple related tables, then explores orders, customers, sellers, products, payments, and reviews using Pandas and NumPy.

## Run

1. Install the repository dependencies:

   ```bash
   pip install -r ../../requirements.txt
   ```

2. Start Jupyter from this directory and open `pandas_session4_project.ipynb`.

The notebook uses the CSV files stored beside it. `olist_geolocation_dataset.csv` is intentionally excluded because it is large and is not used by the current notebook.

## Dataset

The data originates from the public Brazilian E-Commerce dataset by Olist. Keep the filenames unchanged so the notebook can load them correctly.
