# Income Analytics Dashboard

An interactive Microsoft Excel dashboard that explores demographic and employment factors associated with adult income levels.

![Income Analytics Dashboard](Screenshot%202026-08-31%20231847.png)

## Demo video

[Watch the interactive dashboard demonstration](Recording%202026-08-31%20231424.mp4)

## Key results

| Metric | Value |
| --- | ---: |
| Total people | 32,561 |
| High-income people | 7,841 |
| High-income rate | 24.1% |
| Average age | 38.6 years |

## Dashboard highlights

- Income distribution between the `<=50K` and `>50K` groups.
- High-income rates by occupation and age group.
- Geographic distribution of high-income people.
- Interactive filters for sex, marital status, work class, and race.
- KPI cards for population, high-income count, rate, and average age.

## Workbook structure

| Worksheet | Purpose |
| --- | --- |
| `income_evaluation` | Source dataset with 32,561 records |
| `Pivot Tables` | Nine PivotTables that power the analysis |
| `Dashboard` | Interactive KPIs, charts, map, and slicers |

## Technical details

- Microsoft Excel
- 32,561 records
- 9 PivotTables
- 5 charts
- 5 slicers
- No macros or external workbook links
