# Mobile Sales Dashboard

An Excel data-analysis project built from 50,000 mobile-product sales records. The workbook organizes raw and checked data, then uses PivotTables and charts to explore product, brand, regional, and sales-performance patterns.

## Dataset coverage

- Products and brands
- Product codes and specifications
- Prices and quantities sold
- Inward and dispatch dates
- Customers, locations, and regions
- Processor, RAM, ROM, and SSD specifications

## Workbook structure

| Worksheet | Purpose |
| --- | --- |
| `mobile_sales_data` | Original sales dataset |
| `mobile_sales_data_check` | Checked and prepared analysis data |
| `Pivot Tables` | Fourteen PivotTables supporting the dashboard |
| `Dashboard` | Interactive sales summary and visual analysis |

## Technical details

- Microsoft Excel
- 50,000 sales records
- 2 structured Excel tables
- 14 PivotTables
- 3 charts
- 2 slicers
- No macros or external workbook links
