# University Management System

A Python desktop application for university admission and student management. The project demonstrates object-oriented programming through inheritance, abstraction, and encapsulation, with a Tkinter graphical interface.

## Features

- Validate student names, national IDs, ages, and phone numbers.
- Check college eligibility using high-school grades.
- Register students while respecting college capacity.
- Select subjects and calculate tuition fees.
- Display registered students and allow doctors to update GPAs.

## Run

This project uses only the Python standard library. Python 3.10 or newer is recommended.

```bash
python GUI.py
```

Run the command from this directory so the local module imports resolve correctly.
