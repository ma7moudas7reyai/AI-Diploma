# Excel Projects

This directory contains interactive Excel dashboards completed during the AI diploma.

| Project | Focus |
| --- | --- |
| [Super Store](Super%20Store/) | Sales, profit, returns, categories, and regional performance |
| [Employees](Employees/) | Workforce distribution and salary analytics |
| [Income Evaluation](Income%20Evaluation/) | Demographic factors associated with income levels |
| [Mobile Sales](Mobile%20Sales/) | Product, brand, specification, and regional sales analysis |

The dashboards use Excel Tables, PivotTables, PivotCharts, KPI cards, slicers, and timeline filters.
