# BikeStores SQL Project

A Microsoft SQL Server project for creating, loading, and analyzing the BikeStores sample database. It includes practical queries, joins, aggregations, views, CTEs, and business-focused analysis.

![BikeStores project preview](ChatGPT%20Image%20Aug%2016,%202026,%2012_31_29%20PM.png)

## Files

- `2.BikeStores Sample Database - create objects.sql` — creates the database objects.
- `3.BikeStores Sample Database - load data.sql` — loads the sample records.
- `BikeStores.sql` — contains the analysis queries and solutions.
- `Project Details.pdf` — contains the project requirements.

## Run

Open the scripts in SQL Server Management Studio, run the object-creation script, then the data-loading script, and finally execute the analysis queries in `BikeStores.sql`.
