## ⭐ Featured Project

### University Management System

A desktop application built with Python and Tkinter that simulates university admission and student management.

#### Features

- Checks college eligibility using high-school grades.
- Registers students in eligible colleges.
- Validates names, national IDs, ages, and phone numbers.
- Allows subject selection and calculates tuition fees.
- Manages college capacity.
- Displays registered students.
- Allows doctors to update student GPAs.
- Applies OOP concepts including inheritance, abstraction, and encapsulation.

#### Technologies

- Python
- Tkinter
- Object-Oriented Programming

#### Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/ma7moudas7reyai/AI-Diploma.git
   ```

2. Open the project directory:

   ```bash
   cd "AI-Diploma/Projects/University Management System"
   ```

3. Run the application:

   ```bash
   python GUI.py
   ```
