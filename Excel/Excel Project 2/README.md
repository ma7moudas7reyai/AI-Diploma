# Employee Analytics Dashboard

An interactive Microsoft Excel dashboard for analyzing a workforce dataset of 689 employees across departments, countries, centers, and gender groups.

![Employee Analytics Dashboard](dashboard-preview.png)

## Dashboard highlights

- Executive KPIs for total employees, departments, average monthly salary, total monthly salary expense, and gender counts.
- Employee distribution by department.
- Employee distribution by country.
- Gender composition analysis.
- Average monthly salary comparison by department.
- Interactive filters for department, country, center, gender, and start date.

## How to use

1. Download `Employees Dashboard.xlsx`.
2. Open it in Microsoft Excel.
3. Select the `Dashboard` worksheet.
4. Use the filters to explore workforce composition and salary patterns.

> Open the workbook in Microsoft Excel for full PivotTable and slicer functionality.
