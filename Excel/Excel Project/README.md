# Super Store Sales Dashboard

An interactive Microsoft Excel dashboard for analyzing Super Store sales performance from 2014 to 2017. It combines order, return, and regional manager data in a single executive reporting view.

## Dashboard features

- Sales and profit trend analysis
- Sales comparison by category
- Profit analysis by sub-category
- Regional sales distribution
- KPI cards for sales, profit, margin, orders, and returns
- Interactive filters for region, year, category, segment, and order date

## Workbook structure

The final workbook contains five worksheets:

- `Orders` — order-level source data
- `Orders Pivot Tables` — PivotTables used by the dashboard
- `Dashboard` — interactive KPIs and visualizations
- `Returns` — returned-order records
- `Manager` — regional manager reference data
